Loop Framer

Programa pessoal de produção de vídeos animados de divulgação científica e de história.

O que é

O Loop Framer é um programa para Windows que roda no computador do próprio autor. Ele ajuda a produzir vídeos animados para os canais do autor no YouTube: roteiro, animação, render, miniatura, título e descrição.

Uso das APIs do YouTube

Com a autorização do dono do canal, o programa usa as APIs do YouTube só nos canais do próprio autor, para:

  • enviar os vídeos prontos, com título, descrição, legendas, miniatura, playlist e data de publicação;
  • ler as estatísticas desses vídeos (visualizações, tempo assistido, retenção e receita estimada), para melhorar os próximos vídeos.

O programa não é distribuído nem oferecido a outras pessoas, e não acessa canais de terceiros com essa autorização.
